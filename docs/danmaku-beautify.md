# 弹幕美化方案（调研稿）

## 现状

弹幕为置顶透明窗口内的一个圆角卡片（跟随鼠标所在显示器，7 车道轮转，点击穿透）：

- 纯色背景（主题 OverlaySurfaceBrush）+ 1px 边框 + 左侧 4px 严重度色条
- 标题与正文**横向单行**排布，长文本折行后卡片变高
- 动效：右侧匀速滑入至滑出，**无淡入淡出**；结束后直接关窗
- 整窗透明度 0.2~1（文字随之发虚）、字号 12~36、速度/时长可配

问题：样式平淡（纯色块 + 色条）、横排排版在长文本下拥挤、出入场生硬、整窗透明度牺牲文字清晰度。

## 方向一：卡片式精修（保持现有形态，推荐先做）

1. **玻璃拟态背景**：通过 `DwmSetWindowAttribute(DWMWA_SYSTEMBACKDROP_TYPE)` 启用系统 Acrylic 背景模糊（Win11 22H2+ 原生，旧系统自动降级为半透明纯色）；窗口背景改为低不透明度主题色，文字不再随整窗透明度发虚。
2. **立体阴影**：`DropShadowEffect`（BlurRadius 24 / ShadowDepth 8 / 半透明黑），弹幕悬浮于桌面之上。
3. **圆角与呼吸感**：圆角 4 → 12px，内边距加大。
4. **严重度视觉系统化**：左侧色条改为渐变色条；标题按严重度着色（红/黄/绿）；增加 Segoe Fluent Icons 图标（✗ 严重、⚠ 警告、✓ 信息）。
5. **排版改两行**：第一行 = 图标 + 标题（小号粗体）+ 来源徽章（`dsh`/`zcode` 等小圆角标签）；第二行 = 正文（主字号，最多两行折行）。
6. **动效**：入场淡入 200ms；离场前 300ms 淡出再关窗；滑行速度曲线由 EaseInOut 改为**恒速**（弹幕匀速更自然，EaseInOut 会前慢后快再减速）。

## 方向二：经典描边风格（作为设置项与卡片式二选一）

无卡片、纯文字 + 描边（直播/游戏经典样式）：

- 文字为主字号彩色（按严重度或主题色），用 `DropShadowEffect`（ShadowDepth 0、BlurRadius 6~10、黑色）模拟描边保证任意背景可读；
- 整窗透明度仅作用于描边层，文字本体保持不透明；
- 设置页新增「弹幕风格：卡片 / 描边」二选一。

## 方向三：细节增强（可选）

- 来源徽章：按 `Source` 显示来源小标签，一眼分辨消息来自哪个工具；
- 严重度底色微染：Critical 深红底、Warning 深黄底、Info 常规（直播风格）；
- 车道高度随字号自适应（当前固定 62px，大字号会挤压）。

## 工作量与建议

| 项 | 工作量 | 风险 |
|---|---|---|
| 方向一（玻璃 + 阴影 + 两行排版 + 恒速动效 + 图标） | ~半天 | 低（Acrylic 需 Win11 22H2+，自动降级） |
| 方向二（描边风格 + 设置项） | ~半天 | 低 |
| 方向三 | 按项累积 | 低 |

建议先做方向一（效果提升最明显、零行为变化），方向二看使用感受再定。新增设置项仅需「弹幕风格」一个枚举。
